# Sweep 9γ: η λογική του Blesta και του FOSSBilling απέναντι στο MyCS (2026-10-30)

ROADMAP 9γ. Read-only ανάγνωση της λογικής δύο συστημάτων που δουλεύουν χρόνια στον χώρο, ανά θέμα (cron, χρήματα,
τιμολόγια και φόροι, domains, ανανεώσεις, ληξιπρόθεσμα): τι χειρίζονται αυτά που εμείς ίσως όχι. **Μόνο λογική, ποτέ
κώδικας** (FOSSBilling Apache-2.0, Blesta δική του άδεια). Κάθε κενό έγινε finding· οι αποφάσεις του υπεύθυνου
(2026-10-30) και το PR που το έκλεισε είναι παρακάτω. Κάθε PR πέρασε code review και adversarial review (γύροι μέχρι
να μη βρίσκει τίποτα· οι πίνακες στα σχόλια των PR). Γραμμή οδηγός σε όλα: **«keep it simple»**.

## Ανοιχτά (χαμηλή προτεραιότητα)
- Όριο 10 ετών του registry πριν τη χρέωση μιας ανανέωσης κατά παραγγελία.
- Domains premium του registrar ανανεώνονται στην τιμή καταλόγου.
- Το προσωρινό αρχείο PDF του email τιμολογίου (`storage/app/invoices/…`): συγκρούσεις ονομάτων με τη μορφή αρίθμησης, και δεν σβήνεται.
- Επιστροφές και chargebacks του gateway δεν φτάνουν στο Ekdosi (περιμένει το K2).
- Το deploy του Ekdosi να περιμένει τον cron του, όπως το #556.
- Αναμονή αναστολής για όλο τον λογαριασμό (το WHMCS έχει μόνο ανά υπηρεσία): προαιρετικό.
