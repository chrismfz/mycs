# Ελληνικά: γλωσσάρι και κανόνες (2026-10-11)

Μεταφράζεται **μόνο το client area** (`lang/el/*.php` για τα κλειδιά, `lang/el.json` για τα μηνύματα που γράφονται
ως πρόταση στον κώδικα). Το admin έχει **δική του γλώσσα** (ρύθμιση `Admin Language`, default English,
`AdminLocale` middleware): η ελληνική προεπιλογή για τους πελάτες δεν το κάνει μισό Filament-ελληνικά / μισό
upstream-αγγλικά.

## Κανόνες
1. **Οι όροι που χρησιμοποιεί ήδη ο κλάδος μένουν όπως είναι.** Domain, ticket, email, hosting, DNS, nameserver,
   SSL, push, browser, URL. Όχι «Τομέας», όχι «δελτίο».
2. **Όχι μηχανική μετάφραση λέξη προς λέξη.** Πρώτα τι καταλαβαίνει ο πελάτης («Υπόλοιπο», όχι «πίστωση εντός οίκου»).
3. **Σύντομα και ευγενικά, στον πληθυντικό ευγενείας.** Χωρίς «Επιτυχώς!» παντού: «Ο κωδικός άλλαξε.»
4. **Ό,τι είναι φορολογικό ανήκει στο Ekdosi.** Εδώ δεν γράφουμε «Πιστωτικό τιμολόγιο» ούτε «Παραστατικό».
5. Κάθε νέο κείμενο για τον πελάτη μπαίνει και στα ελληνικά. Το `LocalizationTest` αποτυγχάνει αν λείπει κλειδί,
   placeholder (`:name`), μορφή πληθυντικού ή πρόταση του `lang/el.json`.

## Τι δεν καλύπτεται ακόμα
- **Emails/ειδοποιήσεις:** τα templates είναι στη βάση και τα επεξεργάζεται το staff (renderer χωρίς Blade). Ελληνικές
  εκδοχές μπαίνουν από το admin ή με seed στη Φάση 1.
- **Extensions** (gateways, servers): όσα κείμενα δείχνουν στον πελάτη μεταφράζονται όταν τα αγγίξουμε.
- **Η μετάφραση του WHMCS** δεν χρησιμοποιήθηκε ως βάση· μόνο ως έλεγχος για όρους που ξέρουν ήδη οι πελάτες.
